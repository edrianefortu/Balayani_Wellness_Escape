# Balayani Wellness Escape — Tourism Website

A responsive tourism website created from the supplied:
1. FINAL EXAMINATION — Applied Business Tools and Technologies in Tourism
2. Balayani Wellness Escape brochure

## Included required sections
Home, About, Tourism Package/Services, 3-day Itinerary, Gallery (9 destination visuals; QR/payment graphic removed), Destination/Location, Travel Guide, Booking/Inquiry, Contact Us, Footer.

## Digital tourism business features
- Booking/inquiry form
- Calls-to-action
- Digital package presentation
- Interactive Google Maps embed
- Social/contact links
- Digital gallery
- Itinerary presentation
- Promotional pricing
- Responsive mobile navigation
- Customer engagement form feedback

## Run
Open `index.html` in a browser. For best results, use a simple local server such as VS Code Live Server or Laragon.

## Important
The brochure lists a placeholder booking link (`www.reallygreatsite.com`). The website uses the supplied email/mobile/social details and makes the booking section functional as a front-end academic demonstration. Rates, ferry schedules, activities, and availability remain subject to final confirmation, as stated in the brochure.

The supplied brochure states that its photographs/graphics/music/icons are original, properly licensed, or credited in the accompanying asset list. Keep the accompanying brochure with the project documentation.
